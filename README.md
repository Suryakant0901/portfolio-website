# 🚀 Suryakant Chaturvedi - Developer Portfolio

A modern, high-performance, and responsive developer portfolio website showcasing full-stack web applications, AI integrations, technical skills, and experience.

## 🛠️ Tech Stack & Features

- **Core Technologies:** HTML5, CSS3 (Vanilla CSS with Custom Design System), Modern JavaScript (ES6+)
- **Interactive Particle Background:** HTML5 Canvas engine with mouse interaction physics
- **Theme Support:** Dark & Light mode toggle with local storage persistence
- **Animations:** Dynamic typing hero effect, scroll-spy navigation, animated skill progress bars, and counter animations
- **Portfolio Showcase:** Categorized project filtering (MERN Full Stack, AI & Python)
- **Direct Resume Download:** Integrated PDF resume download action
- **Responsive Layout:** 100% mobile-friendly across desktop, tablets, and smartphones

## 🚀 Getting Started

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Suryakant0901/Portfolio.git
   cd Portfolio
   ```

2. **Run locally using any static HTTP server:**
   - **With Python:**
     ```bash
     python -m http.server 5500
     ```
   - **With Node.js (`npx`):**
     ```bash
     npx serve .
     ```
   - Or open `index.html` directly in your browser.

3. **Open in Browser:**
   Visit `http://localhost:5500` in your web browser.
